# Translational Safety Thresholds (TST) Forensic Audit Framework

## Description
Python implementation of the binary Translational Safety Threshold (TST) framework used in the forensic audit of EEG-based stroke rehabilitation AI. This tool quantifies compliance with FDA GMLP, EU AI Act Article 13, and Hebbian plasticity constraints.
